# João Vitor Alves Rodrigues — Site Profissional

Site curricular e portfólio publicado via **GitHub Pages**:

> https://lebot007.github.io/site-joao/

## Stack

- **HTML5** semântico e acessível
- **CSS3** puro (design system com variáveis, tema escuro premium)
- **JavaScript** vanilla (menu, scrollspy, animações de revelação, typewriter)
- Sem frameworks, sem dependências — leve e rápido

## Estrutura

```
├── index.html            # Página principal
├── styles.css            # Estilos (tema "Midnight Tech")
├── script.js             # Interações
├── cv-joao-vitor.pdf     # Currículo para download
├── favicon.svg           # Ícone do site
├── manifest.json         # Manifest PWA
├── og.png                # Imagem de compartilhamento (Open Graph)
├── joao.webp             # Foto de perfil (otimizada)
└── projeto1-4.webp       # Capturas dos projetos (otimizadas)
```

## Como atualizar

1. Edite os arquivos diretamente no GitHub (ou faça commit/push para a branch `main`)
2. O GitHub Pages publica automaticamente em poucos segundos
